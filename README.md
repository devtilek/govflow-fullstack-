# GovFlow — Fullstack Java + React

A portfolio project for processing service requests, inspired by enterprise workflow systems (not affiliated with any government agency).

## Architecture
- Backend: Java 17, Spring Boot 3, Spring Web, Spring Data JPA, Bean Validation, PostgreSQL
- Frontend: React, TypeScript, Vite, REST API, responsive CSS
- Quality: unit tests, GitHub Actions, Docker Compose

## MVP
1. Create and view requests
2. Update request status (NEW, IN_PROGRESS, RESOLVED)
3. Filter requests by status and search by title
4. Form validation, loading and error states
5. Responsive dashboard

## Development
This repository is built in meaningful incremental commits. Never use this project to represent professional work experience; it is a personal portfolio project.
